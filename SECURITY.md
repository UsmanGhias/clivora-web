# Security Policy

CLIVORA Web takes the security of our platform and user data seriously. This document describes our vulnerability disclosure process and security commitments.

## Supported Versions

Only the latest release on the `main` branch deployed to production is supported with security updates.

| Branch / Release | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| < 2.0.0          | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in CLIVORA Web:

1. **Do not create a public GitHub issue.**
2. Send an email to **security@clivora.io** (or reach out via https://usmanghias.co.uk/contact).
3. Include detailed reproduction steps, target endpoint, impact assessment, and proof of concept.

### Our Commitment
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an initial assessment and timeline for remediation.
- Once fixed, we will credit responsible security researchers in release changelogs.
